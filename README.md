\# ESP32 UART Packet Analyser



A UART communication and monitoring project using three ESP32 boards

and a Python graphical user interface.



\## Team Members

\- Manu M

\- Advaitha S



\## Hardware

\- ESP32 Node A

\- ESP32 Node B

\- ESP32 Observer



\## Repository Branches

\- main: project README

\- esp32-firmware: three Arduino firmware sketches

\- python-gui: Python GUI code and dependencies



\## Versions

\- V1: Serial connection and packet inspection

\- V2: Dashboard and communication metrics

\- V3: Transmission and payload controls

\- V4: Baud control, capture export and replay



\## Version Tags

\- Firmware: firmware-v1.0.0 to firmware-v4.0.0

\- GUI: gui-v1.0.0 to gui-v4.0.0



Use matching firmware and GUI versions together.
